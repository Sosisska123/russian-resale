# Русский Ресейл — демонстрационный интернет-магазин

Клиентский сайт магазина ресейл-одежды на React, TypeScript, Vite, React Router, CSS Modules и React Compiler.

## Запуск

Требуется Node.js 20.19+ или 22.12+.

```bash
npm install
npm run dev
```

Проверка production-сборки:

```bash
npm run build
npm run preview
```

## Страницы

- `/` — главная и подборка последних лотов.
- `/catalog` — каталог с поиском и фильтрами по категории, бренду, размеру, состоянию и цене.
- `/product/:id` — карточка товара.
- `/cart` — корзина единичных лотов.
- `/checkout` — форма заказа без регистрации и генерация сообщения для продавца.
- `/favorites` — избранное.
- `/about`, `/delivery`, `/contacts` — информационные страницы.
- `/admin` — демонстрационная панель управления каталогом и локально сохранёнными заказами.

## Перед публикацией

1. В `src/pages/Checkout.tsx` замените `MESSENGER_URL` на реальный адрес аккаунта магазина. Сейчас ссылка ведёт на общий Telegram, а не на конкретного продавца.
2. В `src/pages/Info.tsx` замените демонстрационные ссылки на реальные контакты и соцсети.
3. Замените демонстрационные фотографии и тексты на реальные данные магазина.
4. Панель `/admin` не защищена авторизацией. `localStorage` — хранилище конкретного браузера, не общая база данных: каталог и заказы не синхронизируются между устройствами. Для реального магазина понадобится сервер/API и авторизация.

Данные каталога, корзины, избранного и заказов сохраняются в `localStorage`. При повреждённом JSON хранилище сбрасывает соответствующую коллекцию к значениям по умолчанию.
